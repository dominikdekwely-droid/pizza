# Проект: База данных Пиццерии

**Тема проекта:** Проектирование и разработка реляционной базы данных для управления пиццерией. База включает в себя учет заказов, меню, складских запасов, сотрудников, клиентов и поставщиков.

## Состав команды и зоны ответственности
*   [Доминика Значёнок] — таблицы `categories`, `products`, `product_ingredients`,`ingredients`
*   [Арина Высоцкая] — таблицы `orders`, `order_items`, `customers`, `sizes`
*   [Тимофей Ленько] — таблицы `employees`, `suppliers`, `supplies`, `supply_items`

## Структура репозитория
*   `schema.sql` — DDL-скрипт для создания структуры базы данных (таблицы, ключи, индексы).
*   `seed.sql` — DML-скрипт для наполнения таблиц тестовыми данными.
*   `queries/` — папка с SQL-запросами, разбитыми по неделям и участникам.
